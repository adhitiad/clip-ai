# Anti-slop audit 003, 2026-11-24

Mode: AFTER. Fokus: seluruh codebase frontend harus berlandaskan dua prinsip:
1. UI/UX memakai komponen shadcn. Jika belum tersedia, tambah dengan `bunx --bun shadcn@latest add <item>`.
2. Data yang ditampilkan bersumber dari backend.

File milik agent lain (`src/routes/shorts.tsx`, `src/lib/shorts-api.ts`, `src/env.ts`, `src/routes/api/youtube/**`, `e2e/*.spec.ts`) sengaja tidak termasuk perbaikan. Prioritas: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## UI/UX, shadcn

1. **MEDIUM** `src/components/ModelBadge.tsx:63` tombol "Simpan" masih `<button>` mentah dengan kelas Tailwind. Komponen `Button` sudah terpasang. Timpa dengan `<Button variant="outline" size="sm">`.

2. **MEDIUM** `src/components/ModelBadge.tsx:29` badge "GRATIS" masih `<span>` mentah, bukan komponen `Badge`. Komponen `Badge` sudah terpasang.

3. **MEDIUM** `src/components/states.tsx:21,42` tombol "Coba lagi" dan aksi empty state masih `<button>` mentah. Timpa dengan `Button`. Shadcn juga menyediakan `empty`; pasang dengan `bunx --bun shadcn@latest add @shadcn/empty` jika dipakai untuk merangkum empty state.

4. **MEDIUM** `src/components/LocaleSwitcher.tsx:25-43` tombol pilihan locale memakai `<button>` dengan gaya inline (`style={{...}}`). Timpa dengan `Button` atau `ToggleGroup`; jika `ToggleGroup` belum ada, tambah `bunx --bun shadcn@latest add @shadcn/toggle-group`.

5. **MEDIUM** `src/integrations/better-auth/header-user.tsx:16,18,24` memakai `<img>`, `<div>`, dan `<button>` mentah. Timpa dengan `Avatar`, `AvatarFallback`, `Skeleton`, dan `Button` yang sudah terpasang.

6. **MEDIUM** `src/components/app-shell.tsx:78` trigger dropdown pengguna masih `<button>` mentah. Timpa dengan `Button` dengan `variant="ghost"`.

7. **MEDIUM** `src/routes/niche.tsx:26,42` input Wilayah dan Jumlah masih `<input>` dan `<label>` mentah. Timpa dengan `Input` dan `Label` yang sudah terpasang.

8. **MEDIUM** `src/routes/history.tsx:43,57` tombol pagination masih `<button>` mentah. Timpa dengan `Button`; jika ingin komponen khusus, tambah `bunx --bun shadcn@latest add @shadcn/pagination`.

## Data, backend

9. **LOW** `src/stores/ui.ts:3-4` nilai awal `geo: 'US'`, `maxItems: 10`, `pageSize: 10` adalah konstanta state UI, bukan data domain yang ditampilkan. Namun `geo` default backend adalah `id`. Jika ingin konsisten dengan backend, ambil nilai awal dari kontrak backend, bukan dari pilihan frontend. Tidak ada hardcode data domain lain di `src/`; provider, model, finance, history, trending, health, dan model-status sudah berasal dari backend lewat `apiGet`.

10. **INFO** `src/routes/shorts.tsx` (milik agent lain) masih memakai `input`, `select`, `button`, `form` mentah dan daftar platform hardcode. Tidak saya ubah sesuai batasan file agent lain. Perlu dikoordinasikan terpisah.

## Yang sudah sesuai

- `src/components/ui/**` seluruhnya berasal dari shadcn.
- `ModelProviderGrid`, `ModelBadge`, dashboard, finance, history, niche, tools memakai data backend lewat TanStack Query dan `apiGet`.
- Tidak ada angka, provider, model, atau status rekaan di komponen yang saya kerjakan.
- Semua interaksi utama punya handler nyata.
