# Anti-slop follow-up 011, 2026-11-24

Melanjutkan permintaan: tabel yang belum punya index atau search harus diberi pencarian di database dan backend, dengan konfirmasi terlebih dahulu. Konfirmasi diberikan: search server-side ya, index Alembic ya, sort dan pagination ke backend ya.

## Temuan awal

- `GET /dashboard/history`: hanya `page` dan `page_size`, tanpa search. Model `Clip` tidak punya index di `title_en`, `topic`, atau `score`.
- `GET /finance/summary`: hanya 10 transaksi terakhir, tanpa search dan pagination. Model `Transaction` tidak punya index di `category`, `type`, atau `created_at`.
- `DataTable` melakukan search, filter, sort, dan pagination di client atas data yang sudah dikirim backend.

## Perubahan backend

- `backend/routes/dashboard.py`: `/history` menerima `search`, `sort_by` (`id|title|score`), `sort_dir` (`asc|desc`). Filter memakai `ilike` pada `title_en`, `topic`, `video_url`. Mengembalikan `total`, `search`, `sort_by`, `sort_dir`. Judul fallback memakai `topic` karena model tidak punya `title_id`.
- `backend/routes/finance.py`: endpoint baru `GET /finance/transactions` dengan `search`, `sort_by` (`id|category|type|amount|created_at`), `sort_dir`, `page`, `page_size`, dan respons `TransactionPage`.
- `alembic/versions/0004_table_search_indexes.py`: index untuk `clips(title_en, topic, score)` dan `finance_transactions(category, type, created_at)`. Migrasi sudah dijalankan sampai head.
- Kontrak diperbarui: `docs/API.md`, tabel API `README.md`, `docs/openapi.json` diregenerasi (31 path).

## Perubahan frontend

- `DataTable` sekarang server-driven: kirim `search`, `sortBy`, `sortDir`, `page`, `pageSize` ke induk; nomor urut dihitung dari halaman backend; pagination memakai `total` dari backend.
- `historyPageStore` diperluas dengan `search`, `sortBy`, `sortDir`; `financeTableStore` ditambahkan.
- `historyQuery` dan `financeTransactionsQuery` mengirim seluruh parameter ke backend.
- Halaman history dan finance memakai tabel server-driven; `finance.tsx` mengambil ringkasan dari `/finance/summary` dan baris dari `/finance/transactions`.
